# Food Delivery System Database

## Project OvervieW

The purpose of the project is to demonstrate the design and implementation of a structured SQL database for a real-world food delivery application.

## Database Entities
restaurant
customer
driver
menu_Item
orders
order_Item
payment

## Database Relationships

The main relationships in the database include:

restaurant can have many menu items.
customer can have many orders.
restaurant can receive many orders.
driver can deliver many orders.
order can contain many order items.
menu item can appear in many order items.
Each payment is related with an order.
